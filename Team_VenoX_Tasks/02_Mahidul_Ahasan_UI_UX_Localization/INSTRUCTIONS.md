### 📌 কাজ ১: গিটহাবে মূল `README.md` ফাইলটি আপডেট করো (সময়: ২ মিনিট)

1. তোমার গিটহাব একাউন্ট দিয়ে [https://github.com/CodeWithTanim/OmniShield-AI](https://github.com/CodeWithTanim/OmniShield-AI) রেপোতে যাও। (তানিম ইনভাইট পাঠালে Collaborator হিসেবে একসেপ্ট করে নেবে)।
2. রুট ডিরেক্টরিতে থাকা `README.md` ফাইলে ক্লিক করে উপরে ডানপাশে পেন্সিল (Edit this file) আইকনে ক্লিক করো।
3. এই ফোল্ডারে দেওয়া `README.md` ফাইলের পুরো কন্টেন্ট দিয়ে রিপ্লেস করো।
4. নিচে Commit message বক্সে লেখো:  
   `Update README with Team VenoX roster, design system and stage demo features`
5. **Commit changes** এ ক্লিক করো! 🎯

### 📌 কাজ ২: `docs/DESIGN_SYSTEM_GUIDE.md` ফাইলটি কমিট করো (সময়: ২ মিনিট)

2. ফাইলের নাম দাও: `docs/DESIGN_SYSTEM_GUIDE.md`
3. এই ফোল্ডারের `DESIGN_SYSTEM_GUIDE.md` ফাইলের লেখাগুলো পেস্ট করো।
4. Commit message লেখো:

5. **Commit changes** এ ক্লিক করো!
